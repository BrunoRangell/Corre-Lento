# Corre Lento 🐌

App de corrida do nosso grupo. Corre lento, mas corre: aqui vale a constância, não o pace.

## Baixar

[Baixar o APK (Android)](https://github.com/BrunoRangell/Corre-Lento/raw/main/corre-lento.apk)

1. Toque no link acima e baixe o arquivo.
2. Abra o arquivo e permita a instalação de apps de fontes desconhecidas, se o Android pedir.
3. Abra o Corre Lento e crie sua conta com nome e senha.

O app avisa quando existir uma versão nova.
